PaperAI

面向科研人员的 AI 论文阅读与总结工具，通过大语言模型自动提取论文核心信息：上传 PDF，提取文本，生成 AI 结构化阅读总结，支持基于原文的问答，论文分类，并可导出 Markdown。


#技术栈
- Python 3.11+
- Streamlit
- PyMuPDF
- OpenAI API
- python-dotenv
